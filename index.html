Commit Chord Source

Hear any repo.

Type a public GitHub repo. Its last 100 commits become a tune you can play, share and download.

or try

Press Play. Sound on.Each bar is one commit, oldest on the left.

    Hash is pitch

    The first byte of each commit hash picks the note. Same repo, same tune, every time.

    Author is voice

    Each author gets a color, an octave and a timbre. Solo projects sound solo.

    Merges are chords

    Fixes are short plucks. Reverts slide downward. Long messages hold longer.

    Silence is real

    A day without commits is a rest. A week is a longer one.

    Runs in your browser. Reads the public GitHub API, stores nothing, sends nothing anywhere else. MIT licensed.
